# الذكاء الاصطناعي — الصف السابع

عرض تقديمي تفاعلي لمادة تكنولوجيا المعلومات والاتصالات، الصف السابع الأساسي.
يغطّي الوحدة الرابعة (الذكاء الاصطناعي) والدرس الثاني (مساعدي في الدراسة) من ملخّص المادة.

## التشغيل

افتح `index.html` في المتصفح. لا يحتاج بناء ولا خادم ولا إنترنت (الخطوط وحدها تُحمَّل من Google Fonts، ويسقط العرض إلى خطوط النظام بدونها).

## التنقل

| المفتاح | العمل |
|---|---|
| `←` / `PageDown` / مسافة | الشريحة التالية |
| `→` / `PageUp` | الشريحة السابقة |
| `Home` / `End` | الأولى / الأخيرة |
| `F` | ملء الشاشة |
| `E` | فهرس الشرائح |
| `Escape` | إغلاق الفهرس |

على الهاتف: اسحب يمينًا أو يسارًا. العنوان `#builder` أو `#sim-math` يفتح شريحة محدّدة مباشرة.

## ما في العرض

16 شريحة:

- غلاف وخريطة رحلة.
- ما هو الذكاء الاصطناعي: مقارنة آلة حاسبة مع نظام يتعرّف على الصور، مع تجربة تفاعلية.
- كيف يتعلّم: أربع خطوات قابلة للنقر وتشغيل تلقائي.
- لعبة «هل هذا ذكاء اصطناعي؟» بست بطاقات تُقلب.
- محادثة تُظهر خطأً من AI، ويصحّحه الطالب.
- ست قواعد للاستخدام الآمن.
- وصفة الطلب الجيد: ثمانية مكوّنات، ثم مختبر لبناء الطلب وإرساله.
- محاكاة محادثة رياضيات (تلميحات جمع الكسور) ومحادثة لغة عربية (الفعل المضارع).
- نفس الأداة… طلب مختلف: خمس مواد.
- جودة الإدخال: صورة واضحة، صورة ضبابية، ونص.
- اختبار من سبعة أسئلة، وخلاصة مع تحدّي منزلي.

نقاط XP تُحفظ في `sessionStorage` وتظهر في الشريط العلوي وفي الخلاصة، مع قصاصات احتفال عند إنجاز الألعاب.

## الملفات

| الملف | ما هو |
|---|---|
| `index.html` | الشرائح ومحتواها |
| `styles.css` | التنسيق العام: الشريط، التنقل، الأزرار، الفهرس |
| `slides.css` | تنسيق كل شريحة والمحادثات والألعاب |
| `app.js` | التنقل، شريط التقدّم، XP، الفهرس، ملء الشاشة، السحب على الهاتف |
| `demos.js` | كل التفاعلات والمحادثات |
| `favicon.svg` | أيقونة الموقع |

## ملاحظات

- إجابات «الذكاء الاصطناعي» في المحادثات مكتوبة مسبقًا داخل `demos.js` وتُعرض بحركة كتابة وتفكير. العرض لا يتصل بأي خدمة خارجية.
- الحركة تحترم `prefers-reduced-motion`.
- التصميم موجّه للعرض على شاشة 1366×768 أو أكبر، ويعمل على الهاتف بالتمرير.
